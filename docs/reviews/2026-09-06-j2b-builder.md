## Failed hypotheses / corrections

1. The initial capacity draft placed barrier deletion after durable head. Parent steering
   correctly rejected that as a recoverable publication order. All posts/deletions now
   precede head, while a separate conservative UNPAUSE envelope retains barrier cost and
   head replacement budget. Regressions reject head-ahead-with-unapplied-deletion states.
2. First redo testing exposed omission of deletion-only paths from the permitted post set;
   these have no payload artifact. The check now uses receipt posts as well as artifacts,
   preserves all unrelated base entries, and delegates barrier third-value classification
   to existing `journal.DeleteRedo`. Repeated redo does not add a receipt.
3. Applying the 2422 global temp cap under an already-active UNPAUSE descriptor could exceed
   its proved temporary bound. The selected exception applies only without active.json;
   an owned temp is bounded by the exact frozen descriptor length and complete matching
   bytes. Full malformed descriptor-less temp remains abortable. No bound expansion.
4. A future archive import of a transaction-owned descriptor codec would cycle because
   transaction uses archive costs. The authorized shared-snapshot relocation keeps one
   decoder, identical bytes and negative validation, without modifying existing sources.
