## One finite sequence

Use a single ordered table with operation-specific posts, not five executors:

1. Qualify/reopen/classify under the held lock. Create only missing closed directories through session.mkdir; no recursive cleanup and no uncharged private temp names.
2. Prepare active.json.tmp, full-sync it, exclusively link active.json, sync staging, remove temp and sync. No payload precedes durable active publication.
3. Prepare each descriptor-assigned slot with exact model bytes and primitive sync semantics. The role adapter maps only the five operation shapes and closed artifact targets. Empty discarded evidence remains present empty bytes.
4. Link/reuse all evidence destinations before commit, including evidence whose artifact role is POST. Reuse only byte-identical content-addressed files after verification/sync. Retain every linked orphan after abort.
5. Recheck base and required evidence, then exclusive-link the exact receipt slot; successful link is the logical commit even when following sync fails. Never classify a performed receipt link as an uncommitted failure.
6. Apply actual receipt-bound posts in the capacity model's conservative order: additions/growth before shrink, barrier deletion last among posts. Absent pre uses exclusive link; exact physical pre permits the closed replacement; equal post requires durability confirmation; third private value holds, third intent value remains preserved divergence. No ordinary projection precedes receipt.
7. Derive/publish head after required posts, then sync state and consumed source names. INIT uses absent-only intent/head links. KEEP restores C unchanged and retains D; ADOPT produces C-prime chained from C. Test-only ticket rename never bypasses branch or physical-pre checks.
8. Verify actual receipt/head/projections, remove only proven owned payload/temp names, sync staging, remove active last, sync staging again. Close all handles and lock with joined errors. No new descriptor before completed cleanup.

The primitive prepare currently cleans up on ordinary errors; account its observable create/partial-write/unlink/sync prefixes too. To witness process death between those boundaries, interrupt without running Go defers; do not assume an injected returned error leaves the same state as a killed process.
